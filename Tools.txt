--------- Backend--------
1. Server (listen to request from frontend and send back response received from application back to frontend. Normally, should listen 24/7)
2. Application (Request from frontend is processed by application which may check data from database and may respond with html,css,js file or may return error if request is invalid)
3. Database (Store all the data permanently which can be accessed by application. Suppose in case of login, password may be checked by application and if password matches, then application respond with home-html,css,js file OR if not matches, then send back login-files with appropriate error message)

Server Side API request : Axios (Lot easier to implement compared to Node module, just need to import axios module)

API Authentication: 
1)No auth
2)Basic Auth: Here, username and password (Username:Password) are converted to Base64 format (In postman(format) -> Basic R2FydjpHYXJ2MTIz) which if decoded using Base64 decoder gives Garv:Garv123 (R2FydjpHYXJ2MTIz (Base64 encoded)-> Garv:Garv123 (username:password))
3)API Key Authorization : Just API Key given by server on request and no involvement of Username and Password.    SECURE.....
4)Token based Auth(OAuth and OAuth 2.0): Username and Password to sign in to API Providers website and followed by token generation (3rd party to user) which interacts with API.   (In postman(format) -> Bearer token)
